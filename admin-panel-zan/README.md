# لوحة تحكم بلدية زان (Admin Panel)

لوحة تحكم عربية بالكامل، مستقلة، ومصممة خصيصاً للبلديات اللبنانية. تعتمد على واجهة أمامية فقط (HTML/CSS/JS) ولا تحتاج إلى خادم خلفي (Backend).

## المميزات الرئيسية
*   **عربية 100%**: دعم كامل للغة العربية واتجاه الكتابة من اليمين لليسار (RTL).
*   **بحث ذكي**: محرك بحث فوري يتجاهل التشكيل ويوحد الأحرف (أ/إ/آ -> ا).
*   **أرقام مشرقية**: عرض الأرقام بالتنسيق المشرقي (٠١٢٣٤٥٦٧٨٩) تلقائياً.
*   **تصميم متجاوب**: تعمل بكفاءة على الهواتف والأجهزة اللوحية والحواسيب.
*   **بدون قاعدة بيانات**: البيانات مخزنة مباشرة في ملفات HTML لسهولة التعديل والاستضافة.

## هيكلية المجلدات
*   `index.html`: صفحة تسجيل الدخول.
*   `dashboard.html`: لوحة القيادة والإحصائيات.
*   `manage-news.html`: إدارة الأخبار.
*   `manage-announcements.html`: إدارة التعاميم.
*   `manage-projects.html`: إدارة المشاريع.
*   `manage-gallery.html`: معرض الصور.
*   `assets/`: يحتوي على ملفات التنسيق (CSS)، البرمجة (JS)، والصور.

## كيفية الاستخدام والتعديل

### 1. الاستضافة (Deployment)
هذا المشروع عبارة عن صفحات "ستاتيك" (Static). يمكنك رفعه مباشرة على أي استضافة تدعم HTML مثل:
*   Netlify / Vercel
*   GitHub Pages
*   Shared Hosting (cPanel -> File Manager -> public_html)
*   أو وضعه داخل مجلد `public` في أي خادم ويب.

### 2. تعديل البيانات
بما أن اللوحة لا تستخدم قاعدة بيانات، يتم تعديل البيانات عن طريق تحرير ملفات HTML مباشرة.

**مثال: لإضافة خبر جديد**
1.  افتح ملف `manage-news.html`.
2.  ابحث عن وسم `<tbody>`.
3.  انسخ أحد الأسطر الموجودة `<tr>...</tr>` وألصقه في البداية.
4.  عدل النصوص (العنوان، التاريخ، الحالة).
5.  **هام**: لا تنسَ تعديل خاصية `data-desc` في وسم `<tr>` لتشمل التفاصيل المخفية التي يعتمد عليها البحث الذكي.

```html
<tr data-desc="هنا نضع تفاصيل الخبر الكاملة للبحث...">
    <td>عنوان الخبر الجديد</td>
    <td class="arabic-num" data-date="2023-11-01">٠١ تشرين الثاني ٢٠٢٣</td>
    ...
</tr>
```

### 3. تخصيص الألوان والشعار
*   **الشعار**: استبدل الصورة في `assets/images/Logo Zan.png`.
*   **الألوان**: افتح ملف `assets/css/admin-style-rtl.css` وعدل المتغيرات في الأعلى:
    ```css
    :root {
        --primary-color: #00796b; /* اللون الأساسي */
        --primary-dark: #004d40;  /* اللون الغامق */
    }
    ```

## المتطلبات التقنية
*   متصفح حديث (Chrome, Firefox, Edge, Safari).
*   لا يتطلب أي تثبيت لبرمجيات إضافية (Node.js, PHP, Database غير مطلوبة).
